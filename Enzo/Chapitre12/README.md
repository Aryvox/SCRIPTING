## Consigne

- Créez une liste de processus en Python, où chaque processus génère un nombre aléatoire.
- Lancez les processus et observez-les dans une autre session shell en utilisant la commande 'ps' pour voir les processus en cours d'exécution.
- Identifier leurs processus dans la sortie de la commande 'ps'.Fermez proprement vos processus après observation pour éviter toute fuite de ressources.
