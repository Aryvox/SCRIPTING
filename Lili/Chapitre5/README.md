# Chapitre 5: Sockets

## Consigne

- En utilisant le module socket, développez deux scripts Python : l'un jouant le rôle de serveur et l'autre jouant le rôle de cElient.
- Le script client doit être capable de prendre en argument le message à envoyer au serveur.
- Réalisez un script serveur en utilisant le multithreading pour gérer plusieurs connexions simultanées de clients. Assurez-vous que le serveur peut accepter et traiter les demandes de manière concurrente.
